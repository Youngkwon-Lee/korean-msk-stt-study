## 확인한 범위

과거 ICT 원본 요약 파일에서 집계 필드만 다시 추출하여 기존 공개 표와 대조했습니다. 문장별 오류 발췌·정답·가설은 복사하거나 공개하지 않았습니다. 이번 전사도 집계만 출력합니다. 따라서 확인된 것은 집계 CER와 완전 일치 개수의 재현이며, 과거와 모든 문장별 전사가 동일하다는 검증은 아닙니다.

표본은 과거 선택 기록으로 다시 구성했습니다. 문장 수·음성 길이·정답 글자 수가 과거 기록과 일치하고 이번 Mac→ICT 복사본 72파일의 SHA-256도 각각 일치했습니다. 과거 전송 묶음의 파일별 해시 목록은 없어 11월 6일 입력과의 바이트 단위 동일성을 직접 증명하지는 못합니다. 이번에는 입력 전체 지문과 코드·모델 파일 해시를 manifest에 보존했습니다.

전사 구현은 기본 공개 커밋 `8d0881eb5068b470c587012944bbd57f92ebd10b`의 세 파일이며, 새 순차 실행기의 정확한 SHA-256도 manifest에 있습니다. 해당 실행의 UTC 시작·종료 시각, 조건별 종료 코드와 관련 패키지 버전을 함께 기록했습니다. 난수 시드·결정론 설정은 별도로 강제하지 않았으며 완전한 환경 잠금파일은 아닙니다.

## 실패 시도와 환경 재사용

최초 시도는 Whisper 환경에 SciPy가 없어 전사 전에 실패했습니다. 이 시도는 유효 결과에 포함하지 않았습니다. 기존 Qwen 환경의 SciPy 1.17.1을 작업 전용 경로에서 재사용했고, 같은 Python 3.11.14·NumPy 2.4.6 조합의 48→16 kHz 합성 resample 검증 후 새 출력 디렉터리에서 7조건을 실행했습니다. 공유 환경 패키지는 설치·수정하지 않았습니다.

Nemotron은 full CUDA graph 컴파일에서 드라이버 오류 35를 기록한 뒤 native PyTorch CUDA graph로 fallback했습니다. 드라이버를 변경하지 않았으며 공개 집계는 이 fallback을 포함한 실제 실행 결과입니다. 이 조건의 속도를 다른 그래프 실행 환경의 처리량으로 일반화하지 않습니다.

## 해석의 한계

처리 배속은 음성 길이/전사시간이며 모델 적재시간을 제외합니다. 배속과 메모리는 과거 값과 달랐습니다. 이번 실행은 첫 호출의 import·초기화 및 CUDA 동기화를 포함할 수 있고 다른 CPU·운영 작업도 공존했으므로 속도 변화의 원인이나 안정적인 우열을 검증한 반복 실험은 아닙니다. 메모리는 모델 단독 할당량이 아니라 Windows 화면 프로세스 등을 포함한 카드 전체의 1초 간격 관측값입니다.

36개의 짧은 비대면진료 표본 재실행이며 신규 근골격계 상담 40건 파일럿 결과가 아닙니다. CER는 임상적 의미 보존율·안전성 지표가 아닙니다. 임상 중요 오류, 수정 시간, 긴 상담·소음·치료사 군집성에 대한 검증은 [연구계획](../../docs/protocol.md)의 후속 연구로 남아 있습니다.

공개본에는 음성·원문 전사·파일별 결과·환자정보·비공개 접속 링크·실행 설정·로그·가중치를 포함하지 않습니다.
