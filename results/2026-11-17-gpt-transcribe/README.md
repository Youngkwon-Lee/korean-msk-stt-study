## 요청 속도와 측정 구간

| 지표 | gpt-transcribe | Qwen 상주 후 |
|---|---:|---:|
| 36건 요청 완료 시간 합계 | 46.88초 | 114.71초 |
| 요청 중앙값 | 1.07초 | 3.00초 |
| 표본 내 p95 | 2.57초 | 4.55초 |
| 요청 범위 | 0.70–2.74초 | 2.43–4.68초 |

- 두 모델 모두 같은 순서로 원본 WAV 36개를 한 번씩 순차 요청했습니다. p95는 36개 관측치의 nearest-rank 값이며 운영 지연 분포나 SLO를 추정한 수치가 아닙니다.
- GPT는 Mac→OpenAI HTTPS 업로드·서버 처리·응답을 포함합니다. Qwen은 ICT 내 loopback HTTP 업로드·큐·디코딩·추론·결과 조회·작업 삭제를 포함합니다. 호출 위치와 네트워크 경로가 달라 순수 엔진 연산 성능 비교로 사용하지 않습니다. 채점·집계 시간은 개별 요청 시간에서 제외했습니다.
- Qwen은 첫 원음 1회의 워밍업을 별도로 수행한 뒤 36개 채점 요청을 새 작업 ID로 다시 실행했습니다. 워밍업 **75.39초**는 위 합계와 정확도 분모에서 제외했습니다. 자식 프로세스의 모델 적재 계측은 그중 **66.05초**였습니다. GPU 1은 시작 시 524 MiB/0%였고 기존 공유 잠금을 유지했습니다.
- Qwen이 반환한 디코딩·추론·CUDA 동기화 구간 합계는 **69.12초**, 중앙값은 **1.68초**였습니다. GPT API는 이와 대응되는 서버 내부 처리 시간을 제공하지 않아 같은 종류의 엔진 시간 비교는 하지 않습니다.
- 입력 길이 합은 149.04초입니다. 이 실험은 완성된 발화별 파일 요청이며, 녹음 중 부분 결과·VAD 경계·전체 대화의 최종 지연을 검증한 것은 아닙니다.

## 입력·모델·채점 조건

원본 WAV/TXT 72개를 이전 선택 목록으로 다시 확보하고 파일명·크기·전체 SHA-256을 대조했습니다. 입력 지문은 `80f76331e35ae2fe611654af70e3adfc55f73c1d9a1e7316dffcdaa043f16ed3`, 용어 주석 지문은 `481fa3cb1fbc6cd769012e00fad300084966fa78579fdff7a25974620be890b7`로 기존 실행과 같습니다. 두 실행 전후 입력 지문도 확인했습니다.

- GPT 요청 모델 ID는 **`gpt-transcribe`**입니다. 공식 문서에 맞춰 `languages[]=ko`, `response_format=json`을 사용했고 정답·의료 용어·문맥 프롬프트를 제공하지 않았습니다. `whisper-1` 전용 설정을 재사용하지 않았으며 `temperature`는 보내지 않았습니다. 응답은 구체적인 모델 버전 식별자를 반환하지 않았으므로 요청 ID 이상의 버전 고정을 주장하지 않습니다. 자동 재시도는 없습니다.
- Qwen은 기존 1.7B 로컬 가중치·float16·eager attention·batch 1·최대 1,024 토큰·30초 내부 분할을 유지했습니다. 공용 서비스 소스 `18cee5a041d4c10c20b863b6e86d1ab6d9086053`의 실제 HTTP→GPU 경로를 사용했습니다. 실행한 서비스·Python 클라이언트 14개 파일 해시를 현재 원본 코드와 대조했습니다. GPU는 기존 Quadro RTX 5000이고 라이브 패키지 버전은 실행 증거에 있습니다. 모델 다운로드·설치·드라이버 변경은 없었습니다.
- [비교 코드](../../scripts/compare_api.py)의 같은 정규화 CER과 [용어 정렬](../../scripts/clinical_terms.py)을 사용했습니다. 띄어쓰기·문장부호를 제거한 기존 CER이므로 임상 의미 평가를 대체하지 않습니다. 이 표본과 과거 결과를 이미 알고 있는 탐색 연구이며 눈가림된 사전등록 평가가 아닙니다.

이번 표본에서 GPT는 요청이 더 빨랐고, 지정 용어 보존은 Qwen이 나았습니다. 36문장·37용어의 점수만으로 통계적 동등성이나 모델의 일반적 우월성을 주장하지 않습니다. 모델 선택에는 신규 한국어 근골격계 상담 표본에서의 중요한 정보 보존·수정 부담 검증이 추가로 필요합니다.

## 검증·공개·정리

연구 코드 테스트 **19개**가 통과했습니다. GPT에 복수 언어 필드를 보내고 정답·용어 힌트·구형 매개변수를 넣지 않는 요청과 latency 중앙값·p95 집계를 검증했습니다. 모의 테스트와 실제 GPT 36회·Qwen 채점 36회+워밍업 1회 실행은 별도 증거입니다.

기존 키 재사용과 해당 AI Hub 샘플의 외부 API 이용 허용 범위에서 실행했습니다. API 키는 Mac 프로세스에만 주입했고 ICT에 보내거나 새 키 파일을 만들지 않았습니다. Mac·ICT의 시험용 원음·정답 복사본 각 72개, 개별 전사문, 임시 전송 정보·테스트 키·상태 DB를 삭제했습니다. GPU 모델과 테스트 API를 종료하고 공유 잠금을 반환했으며 기존 운영 STT 사용자 서비스 두 개는 active였습니다. 원본 Drive와 앱 운영 제공자는 변경하지 않았습니다.
