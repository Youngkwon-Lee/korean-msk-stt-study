# 2026-11-17 Whisper API와 Qwen 1.7B 정확도 비교

동일한 원음·정답 36쌍(149.04초, 정규화 정답 504자)을 이번에 두 제공자에서 다시 전사했습니다. **Qwen3-ASR 1.7B의 CER은 1.19%(6/504), OpenAI `whisper-1` API는 3.17%(16/504)**였습니다. 지정한 의료 용어 표기 보존 오류는 각각 **0/37, 5/37**이었습니다. 속도 테스트의 합성 문장이 아니라 이전 AI Hub 의료진·환자 음성 샘플입니다. 근골격계 상담만을 대표하는 표본은 아닙니다.

Whisper API와 자체 호스팅 Whisper large-v3/turbo는 서로 다른 제공 조건입니다. 이전 turbo의 1.98%를 API의 정확도로 인용하지 않습니다. 이번 Qwen CER·완전 일치는 11월 16일 집계와 같았지만, 과거 값 복사가 아니라 현재 서비스 설정으로 다시 실행한 출력의 점수입니다.

## 입력과 실행

- 원본 72개 WAV/TXT 파일을 이전 선택 목록대로 다시 확보하고 이름·크기를 확인했습니다. `sorted filename UTF8 + binary SHA256(file)`를 이어 해시한 전체 지문 `80f76331e35ae2fe611654af70e3adfc55f73c1d9a1e7316dffcdaa043f16ed3`가 11월 16일 입력과 일치했습니다. 각 실행 전후에도 지문을 확인했습니다.
- 사용자가 원음의 외부 API 이용 조건을 확인하고 이번 전송을 명시적으로 허용했습니다. OpenAI 키는 승인된 Mac 프로세스에서만 읽었으며 ICT에 보내거나 키 파일을 새로 만들지 않았습니다.
- Whisper API는 원본 WAV마다 `whisper-1`, `language=ko`, `temperature=0`, `response_format=json`, prompt 없이 한 번씩 요청했습니다. 자동 재시도는 없습니다.
- Qwen은 별도 공용 STT 서비스의 실제 HTTP 업로드→상주 GPU→조회·삭제 경로를 사용했습니다. 기존 ICT 가중치·Qwen 환경, float16, eager attention, batch 1, 최대 1,024 토큰, 30초 내부 분할 설정입니다. 모델은 같은 프로세스에서 재사용했습니다. 원음별 API 요청이므로 임의의 새 문장 경계를 만들지 않았습니다.
- [비교 코드](../../scripts/compare_api.py)는 결과를 비공개 파일에 기록하고 콘솔에는 진행 개수와 집계만 출력합니다. 집계에 코드·입력·주석 해시와 실행 시각이 있습니다. Qwen 서비스의 실행 코드 해시는 서비스 레포의 별도 증거에 기록합니다.
- HTTP 총합은 Qwen 253.97초, Whisper 61.80초입니다. Qwen에는 첫 모델 적재·GPU 대기·작업 큐·조회·삭제, Whisper에는 Mac 네트워크·업로드·API 응답이 포함돼 순수 추론 시간 비교로 사용하지 않습니다.

## 의료 용어 평가의 정의

이번 두 모델 출력을 보기 전에 정답에서 25개 용어 유형의 37회 출현(29문장)을 고정했습니다. 공개 [용어 평가 코드](../../scripts/clinical_terms.py)의 사전과 정규화 문자 정렬을 사용합니다. 각 출현 위치에서 문자 대체·삭제·용어 내부 삽입이 있으면 표기 보존 오류 1회로 셉니다. 동일 용어가 여러 문장에 나와도 각각 분모에 포함합니다. 띄어쓰기 차이, 용어 밖 조사의 변경은 용어 오류로 세지 않습니다.

| 범주 | 용어 출현 수 | Qwen 오류 | Whisper API 오류 |
|---|---:|---:|---:|
| 신체 부위 | 9 | 0 | 0 |
| 질환 | 10 | 0 | 1 |
| 과거력·가족력 | 2 | 0 | 1 |
| 손상 | 2 | 0 | 1 |
| 검사 수치 | 2 | 0 | 0 |
| 증상 | 9 | 0 | 2 |

주석 지문은 `481fa3cb1fbc6cd769012e00fad300084966fa78579fdff7a25974620be890b7`이며 두 실행에서 동일했습니다. 이전 벤치마크 결과를 이미 알고 있는 표본에서 정답을 보고 정한 목록이므로, 눈가림된 사전등록 평가가 아닙니다. 이 점수는 **지정 용어의 문자 보존**이며 의미적 동등성, 중요 오류, 부정·좌우·수치·발화자 전체를 판정한 검증된 임상 척도가 아닙니다. 예를 들어 ‘통증 있음/없음’이 바뀌어도 ‘통증’이라는 용어 자체는 보존될 수 있습니다.

## 해석과 후속 검증

이 표본에서는 정확도를 우선할 때 Qwen을 유지할 근거가 있습니다. 그러나 36문장·37용어에서 0회였다는 사실은 실제 상담의 의료 오류가 없다는 뜻이 아닙니다. 짧은 같은 화자 발화가 반복된 탐색 표본이며, 자연스러운 긴 상담·소음·방언·근골격계 전문 용어·구간 경계 오류를 충분히 포함하지 않습니다. 통계적 우월성·임상 안전성을 주장하지 않습니다. 기존 계획의 신규 40상담 파일럿에서 중요한 정보 보존과 전문가 수정 부담을 평가해야 합니다.

CER은 이전과 비교하려고 띄어쓰기·문장부호를 제거한 기존 정규화를 사용했습니다. 단위 기호 등을 손실시킬 수 있어 임상 의미 평가는 원형 전사와 원음으로 별도 수행해야 합니다. `patient`/`staff`는 원본 파일 그룹이며 실제 진료 표본의 대표성을 검증한 구분이 아닙니다.

중간 전사는 [별도 서비스 레포](https://github.com/Youngkwon-Lee/kinelo-stt)의 발화 구간별 전달 클라이언트에서 시험합니다. 이 정확도 비교는 완성된 원본 발화별 결과이며, 파일을 새로 잘랐을 때의 정확도를 검증한 것은 아닙니다. 서비스 코드를 연구 레포에 합치거나 앱 운영 제공자를 전환하지 않았습니다.

## 검증과 공개 범위
