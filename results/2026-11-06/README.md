# 2026-11-06 한국어 36문장 예비 비교

[집계 CSV](results.csv)와 [집계 JSON](results.json)은 실제 실행 출력에 남은 반올림 수치의 복원본입니다. 원격 `summary.json` 원본을 다시 확보하지 못했습니다. 문장별 원문·가설·음성·모델 가중치·내부 접속 정보는 포함하지 않습니다.

- 5개 모델, Whisper 두 모델의 VAD 켬/끔을 포함한 총 7조건.
- 같은 36쌍을 Quadro RTX 5000 16 GiB에서 순차 실행했습니다.
- 새로운 근골격계 상담 40건 연구의 자료가 아닙니다. 표본의 독립 화자 수와 대표성은 확인되지 않았습니다.
- `patient`와 `staff`는 파일명 그룹입니다. 실제 환자·의료진의 임상적 대표성을 증명하지 않습니다.
- CER는 퍼센트 단위이며 정규화 후 편집 오류율입니다. 의미 보존률·임상 안전성 수치가 아닙니다.
- 배속은 모델 로딩시간 제외. 메모리는 1초 간격 GPU 전체 관측 최대값입니다.
- Nemotron 언어 표식 `<ko-KR>`을 제거한 최종 CER는 11.11%입니다. 표식을 포함한 초기 계산은 사용하지 않습니다.

## 오류 유형의 관찰

Whisper large-v3에는 발화와 무관한 자막·광고 관련 추가 생성과 빈 출력이 관찰됐습니다. Turbo에는 증상 부위·출혈 관련 단어·가족력 용어의 오인식이 있었고, VAD 켠 조건에는 호소 부위가 일반 접속 표현으로 바뀐 오류가 있었습니다. Qwen 0.6B에는 사물명·가족력 용어 오류, Qwen 1.7B에는 주체·상태 표현 변경이 남았습니다. Nemotron에는 사물명·증상 서술의 여러 오인식이 있었습니다.

이는 오류 유형의 서술적 요약입니다. 임상 중요 오류율이나 환각률을 정식 주석해 계산한 것이 아니며, 개별 전사문은 공개하지 않습니다.

## 출처·재현성의 한계

집계 표는 과거 로그의 수치에서 복원됐고, 이번 공개 코드로 GPU를 다시 실행한 결과가 아닙니다. 원래 일회성 benchmark 스크립트와 원격 환경 잠금파일은 이 아카이브에 없습니다. [복원 코드의 방법과 검증 범위](../../docs/benchmark-method.md)를 함께 읽어야 합니다.

원격 실행용 표본과 전송 임시 파일은 실험 종료 시 삭제 확인됐다는 당시 기록이 있습니다. 그 삭제 상태를 공개일에 원격으로 다시 점검한 것은 아닙니다. 원본 데이터의 이용 조건이 확인되지 않아 데이터를 배포하거나 새 연구의 모집·활용 권한을 주장하지 않습니다.
