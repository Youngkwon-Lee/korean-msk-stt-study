# 한국어 공개 의료 음성 1,800문장 확대 비교

실제 실행일: 2026-11-18 한국시간. GPT-Transcribe와 Qwen3-ASR 1.7B의 동일 원음 대응 기술 평가다. **확대 정확도 1,800건과 별도 직렬 속도 120건을 모델별로 완료**했다. 실제 근골격계 상담을 모집하거나 임상 의미 오류를 판정한 연구는 아니다.

## 자료와 실행 검증

기존 보유 AI Hub 샘플 3,735쌍에서 개발 항목 또는 동일 정답 90개와 코드 내부 중복 정답 8개를 제외했다. 6개 출처 코드별 300개를 고정해 1,800문장·1,135개 정규화 정답 문구·26,065자를 평가했다. 코드 수는 화자 수가 아니며 실제 독립 화자/세션 수는 미상이다. 역할 라벨은 staff 1,200개, patient 600개다.

원음은 모두 48 kHz·16-bit·mono WAV이며 총 6,501.18초(108.35분), 최장 31.5초다. 1,800개 파일 해시가 모두 다르며 맥과 ICT의 전체 해시가 일치했다. 전송은 암호화와 무결성 검증을 거친 묶음으로 수행했고, 검증 뒤 임시 암호화 사본 19개·전송 폴더·전송 키/URL을 정리했다. 원본 Drive 자료와 비공개 연구 검토용 사본·개별 출력은 보존했다.

선택 지문: `dcfdcac189d11835d0ed28efbf6be3edaeb755a8d321d7b84712ef6b2758b624`. 실행 원음 명세 지문: `f2e2310db7318d4e21d65ea3b52384db7ed34bee9e1dc2a6d92562c61feb087e`. 25개 개발 사전의 자동 주석 지문: `9aca48fd818ff36cdf859ffe331a31c111d109c2919c00c57ba4a53280cc06b1`. 개별 경로·ID·정답·전사는 공개하지 않는다.

## 정확도와 지정 문자열 보존

| 항목 | GPT-Transcribe | Qwen3-ASR 1.7B |
|---|---:|---:|
| 전체 CER | 2.85% (744/26,065자) | 2.52% (658/26,065자) |
| 정규화 완전 일치 | 1391/1,800 (77.28%) | 1409/1,800 (78.28%) |
| staff 라벨 CER | 2.70% | 1.87% |
| patient 라벨 CER | 3.08% | 3.45% |
| 지정 문자열 오류 | 33/699 (4.72%) | 18/699 (2.58%) |
| 전사 기술 실패 | 0/1,800 | 0/1,800 |

CER은 띄어쓰기·문장부호 등을 제거한 문자 편집거리이며 의미 정확도와 구분한다. 지정 문자열은 정답에서 미리 고정한 25개 사전 유형의 699회 출현이다. 짧은 표현·다의어의 문맥 적격성을 독립 검토하지 않았고, 임상적 중요도·부정·측·수치의 의미 오류는 미평가다. ‘문자열 보존 오류’가 의료 의미 오류 전체를 대표한다고 해석하지 않는다.

이 범주는 탐색적 사전 라벨이다. 특히 적은 분모의 비율을 안정적인 임상 오류율로 해석하지 않는다.

## 대응 차이와 한계

전체 공통 성공 집합의 CER 차이(GPT−Qwen)는 **+0.330%p**다. 동일 정답 문구 그룹별 대응 재표집 2,000회(seed 20261117)의 중앙 95% 범위는 +0.066~+0.599%p다. 이 범위는 관찰된 코퍼스에 조건부인 민감도 분석이며 미확인 화자 의존성을 보정하지 못한다. 모집단 신뢰구간·임상적 우월성 검정으로 보고하지 않는다. p값은 계산하지 않았다.

문장 수를 독립 환자 수로 환산하지 않는다. AI Hub 제공 정답의 독립 원음 검토와 근골격계 특화 표본은 확보되지 않았다. 고정된 300개 정답 검토용·699개 문자열 문맥 검토용 비공개 빈 평가표를 준비했으며 판정값을 채우지 않았다. 검토 후 정답이 바뀌면 기존 결과와 별도 버전/민감도 분석을 보존해야 한다.

## 별도 직렬 속도와 출력 변화

속도 하위표본 120개는 출력 확인 전에 코드별 20개씩 고정했다. 같은 120개 원음은 총 445.38초다. 아래는 정확도 배치의 처리시간과 분리해 다시 실행한 값이다.

| 항목 | GPT-Transcribe | Qwen3-ASR 1.7B |
|---|---:|---:|
| 직렬 요청 수 | 120 | 120 |
| 중앙값 | 0.961초 | 2.808초 |
| p95 nearest rank | 1.374초 | 4.164초 |
| 같은 입력의 정규화 출력 차이 | 5/120 | 0/120 |

GPT는 맥에서의 HTTP 왕복이며 Qwen은 ICT에서의 로컬 디코드+추론이다. Qwen 서버 큐·업로드·HTTP·앱 표시·발화 종료 감지 시간은 포함하지 않는다. 두 측정 구간을 순수 모델 연산 속도나 실제 앱 전체 지연의 직접 비교로 취급하지 않는다. p95는 nearest-rank 방식이다.

정확도 단계는 API 최대 동시 요청 4개, Qwen 최대 추론 배치 4개였고 속도 단계는 둘 다 직렬/유효 배치 1개였다. 출력 차이는 단계 사이의 설정·서버 상태·수치 연산 등의 영향을 분리한 동일 조건 반복성 추정치가 아니다. 직렬 출력으로 정확도 1,800개 결과를 교체하지 않았다.

## 고정 조건과 재현성

[실행 변경 기록 v0.2a](../../docs/execution-amendment-v0.2a.md)은 확대 출력 확인 전에 공개했다. 30초 초과 파일 한 개는 Qwen 서비스의 기존 30초 분할·비어 있지 않은 결과를 띄어 이어 붙이는 규칙으로 처리했다. GPT에는 동일 원음 전체를 입력했다. Qwen은 Korean, float16, eager attention, max_new_tokens=1024이며 합성 무음 워밍업을 분리했다. 정답/용어 프롬프트·LLM 교정·요약은 사용하지 않았다. 다른 GPU 작업과 운영 STT를 중지하지 않고 GPU 1의 기존 임대를 사용했다.

[원본 데이터 설명](https://www.aihub.or.kr/aihubdata/data/view.do?aihubDataSe=data&currMenu=115&dataSetSn=208&topMenu=100), [계획 v0.2](../../docs/publication-plan-v0.2.md), [실행/집계 코드](../../scripts/run_expanded.py), [수치 JSON](results.json), [CSV](results.csv), [실행 증거](execution-manifest.json)를 함께 읽는다. API 모델은 요청 별칭과 시각을 보존하며 서버 revision이 반환되지 않았다면 그 한계를 남긴다. 모델 가중치·원본·전사/정답·개별 수치 벡터·자격증명은 공개하지 않는다.

이번 결과는 공개 의료 음성의 탐색적 기술 비교다. 후속 실제 한국어 근골격계 상담 연구는 협력기관·윤리 검토·동의·독립 평가자·40상담 파일럿과 그에 따른 군집 표본 수 산출을 별도로 진행해야 한다.
