# 확대 평가 표본 준비 — 모델 결과 아님

이 파일은 준비 시점의 기록이다. 후속 [1,800문장 실제 모델 비교와 직렬 120건 측정](../2026-11-18-expanded/README.md)은 별도로 완료·보존했다.

2026-11-18 한국시간에 기존 보유 AI Hub 샘플의 WAV/TXT 3,735쌍과 정답 텍스트 전체를 확인했다. [기술·임상 연구 확장 계획 v0.2](../../docs/publication-plan-v0.2.md)와 [집계 JSON](corpus-summary.json)을 함께 읽는다.

기존 개발 파일 또는 동일 정규화 정답 90개를 제외하고, 코드 내부 중복 정답 8개를 제거했다. 적격 항목 3,637개에서 원본 코드별 300개씩 **1,800개**를 선택했다. 전 코드 합계의 서로 다른 정규화 정답은 **1,135개**다. 코드 6개를 독립 화자 6명으로 해석하지 않으며 실제 화자 수는 미상이다.

정답 검토 하위표본 300개와 지연 측정 하위표본 120개도 출력 확인 전에 고정했다. `staff`/`patient`는 원본 역할 라벨이다. 선택 메타데이터의 바이트 합은 624,253,680이며 원음의 바이트 동일성·총 길이는 아직 검증하지 않았다.

선택 manifest SHA-256: `dcfdcac189d11835d0ed28efbf6be3edaeb755a8d321d7b84712ef6b2758b624`.

이 지문은 비공개 선택 명세의 변경 감지용이다. 원본 경로·Drive ID·문장·선택 목록은 공개하지 않는다. 정답 해시는 읽은 정답을 strip한 UTF-8 내용에 대한 것으로 원본 TXT 파일 바이트 해시와 다르다. 음성 바이트를 검증해 실행용 명세를 새 경로에 만들 때 선택 지문과 실행 지문의 연결을 보존해야 한다.

**확대 표본의 GPU/API 추론을 시작하지 않았다.** CER·용어 오류·임상 의미 오류·처리 속도의 새 수치는 없다. 기존 36문장 결과는 각각 기존 날짜의 결과 폴더에 보존한다.
