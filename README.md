# Korean MSK STT Study

한국어 근골격계 물리치료 상담에서 음성인식의 **중요 임상 정보 보존과 전문가 수정 부담**을 평가하기 위한 연구계획·빈 서식·비교 도구·집계 결과입니다.

**상태: 설계 초안 / 파일럿 모집 전.** 기관·IRB 승인, 환자 녹음 수집, 본연구 또는 제품의 임상적 안전성을 입증한 저장소가 아닙니다. 논문으로 게재되었다는 의미도 아닙니다.

## 연구자료

- [연구계획서 v0.1](docs/protocol.md): 선행연구, 차별점, 대응 비교 설계, 평가·분석, 표본 수 산출 계획.
- [참여자 설명문](docs/forms/participant_information.md): 환자와 참여 치료사에게 설명할 초안.
- [연구 참여·녹음·자료 이용 동의서](docs/forms/recording_consent.md): 환자·치료사가 각각 작성하며 건강정보 동의는 별도로 구분합니다.
- [독립 평가·수정시간 평가표](docs/forms/evaluation_forms.md).
- [빈 CSV 기록지와 항목 사전](templates/): 작성된 서식이나 참여자 데이터는 포함하지 않습니다.
- [표본 수 계산 코드](scripts/sample_size_plan.py)와 [18개 가정별 예시](results/sample_size_scenarios.csv).

초기 제안은 **40상담 외부 파일럿**이며, 이는 검정력을 보장한 본연구 표본 수가 아닙니다. 본연구 N은 대응 불일치쌍·치료사 군집성·최소 중요 차이를 정한 뒤 별도 시뮬레이션으로 확정해야 합니다. 설명문과 동의서는 기관·책임자·연락처·보관기간·철회·보상 항목을 확정하고 기관 검토를 거쳐야 사용할 수 있습니다.

위 값은 과거 실제 명령 출력에 보존된 집계값을 복원한 것입니다. 모델 적재시간은 배속에서 제외됐고, CER은 의미 이해율이나 임상 안전성 수치가 아닙니다. `patient`/`staff`는 입력 파일명상의 그룹으로, 실제 환자·의료진의 신원이나 임상적 대표성을 검증했다는 뜻이 아닙니다. 예비 표본 36쌍과 계획된 신규 40상담 파일럿은 별개입니다.

**재현성 제한:** 원본 음성·전체 정답/전사·모델 가중치·원격 환경 잠금파일은 배포하지 않습니다. 당시의 일회성 실행 스크립트가 보존되지 않아 [현재 비교 코드](docs/benchmark-method.md)는 기록된 방법에 기반한 휴대 가능한 복원 구현입니다. 공개 코드로 위 GPU 수치를 재실행하거나 원본과 비트 단위 일치를 확인한 것은 아닙니다. 단위 테스트·합성 fixture 검증과 과거 GPU 실측을 구분합니다.

## 비교 코드

[사용법과 방법 차이](docs/benchmark-method.md)를 먼저 읽으세요. 기존의 별도 모델별 환경과 로컬 가중치를 사용하며 자동 설치·모델 다운로드·유료 API 호출을 하지 않습니다. 허용된 자체 자료에 대해서만 실행합니다. 새 실행 결과는 `private-runs/`에 두고 공개할 집계는 별도로 검토합니다.

```sh
python3 -B -m unittest discover -s tests -v
python3 -B scripts/sample_size_plan.py
python3 -B scripts/benchmark.py --help
```

GPU 추론에 필요한 패키지를 테스트를 위해 설치할 필요는 없습니다. 이 저장소에는 배포 API 서버·자동 실행 서비스·앱 활성화 코드가 포함되어 있지 않습니다.

## 공개 범위

포함: 계획 초안, 공개 문헌 링크, 빈 서식, 집계 수치, 측정 방법과 코드, 합성 테스트.

제외: 원본 음성·영상, 원문 전사, 개별 상담별 결과, 서명 동의서, 환자/치료사 식별자, 비공개 Drive·운영 URL, 자격증명과 내부 접속 정보, 모델 가중치. 합성 fixture는 테스트 중 임시 생성하며 실제 사람의 녹음이 아닙니다.

`.gitignore`와 `scripts/check_publication.py`는 일부 유형·패턴을 점검할 뿐 개인정보 부재를 보장하지 않습니다. 공개할 파일을 명시적으로 선택하고 내용을 검토해야 합니다. 원본 데이터의 이용 조건이 확인되지 않아 데이터를 공개하거나 재배포하지 않습니다.

## 권리·인용

공개 접근과 재사용 허가는 서로 다릅니다. 현재 별도의 재사용 라이선스는 지정하지 않았습니다. 모델·패키지·문헌·데이터의 권리는 각 원저작자와 이용 조건을 따릅니다. 이 저장소는 IRB 승인서나 데이터 이용 허가를 대신하지 않습니다. [인용 정보](CITATION.cff)는 논문 게재를 의미하지 않습니다.
