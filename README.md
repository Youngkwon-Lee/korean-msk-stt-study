# Korean MSK STT Study

한국어 근골격계 물리치료 상담에서 음성인식의 **중요 임상 정보 보존과 전문가 수정 부담**을 평가하기 위한 연구계획·빈 서식·비교 도구·집계 결과입니다.

**상태: 공개 코퍼스 1,800문장 비교 완료 / 임상 파일럿 모집 전.** 기관·IRB 승인, 환자 녹음 수집, 본연구 또는 제품의 임상적 안전성을 입증한 저장소가 아닙니다. 논문으로 게재되었다는 의미도 아닙니다.

[2026-11-18 확대 결과](results/2026-11-18-expanded/README.md): Qwen 1.7B CER **2.52%**, GPT-Transcribe **2.85%**, 지정 문자열 오류 **18/699·33/699**였습니다. 환자 라벨 CER은 GPT **3.08%**, Qwen **3.45%**로 순서가 달랐습니다. 독립 화자 수와 정답·임상 의미 검토는 미완료입니다. 직렬 120건은 별도 실행했으며 측정 구간 차이를 보고합니다.

- [검수 품질·이용권·승인된 로컬 평가용 데이터 게이트](docs/review-release-governance.md): 2인 검수·동의/이용권·전문가 QA를 별도로 확인하고, 실제 승인 전 외부 검수·모델 학습/재사용은 차단합니다.

- [참여자 설명문](docs/forms/participant_information.md): 환자와 참여 치료사에게 설명할 초안.

## 36문장 예비 비교와 GPU 재실행

[2026-11-16 실제 GPU 재실행 보고서](results/2026-11-16/README.md) / [CSV](results/2026-11-16/results.csv) / [JSON](results/2026-11-16/results.json) / [실행 증거](results/2026-11-16/execution-manifest.json) / [기존 값과 비교](results/2026-11-16/comparison.csv).

5개 모델·7조건을 순차 실행해 모두 종료 코드 0을 확인했습니다. CER와 완전 일치 개수는 기존 집계와 7/7조건에서 일치했고, 속도·메모리는 달랐습니다. 아래는 새 실행 값이며 [2026-11-06 복원 자료](results/2026-11-06/README.md)도 보존합니다.

| 모델 | VAD | 전체 CER | 완전 일치 | 처리 배속 |
|---|---|---:|---:|---:|
| Whisper large-v3 | 끔 | 12.70% | 27/36 | 4.23배 |
| Whisper large-v3 | 켬 | 11.11% | 29/36 | 4.31배 |
| Whisper large-v3-turbo | 끔 | 1.98% | 28/36 | 9.83배 |
| Whisper large-v3-turbo | 켬 | 2.78% | 27/36 | 8.97배 |
| Qwen3-ASR 0.6B | 별도 통제 안 함 | 1.98% | 31/36 | 1.64배 |
| Qwen3-ASR 1.7B | 별도 통제 안 함 | 1.19% | 32/36 | 1.82배 |
| Nemotron 3.5 ASR 0.6B | 별도 통제 안 함 | 11.11% | 14/36 | 1.39배 |

새 실행은 36문장·149.04초·정규화 정답 504자를 사용했습니다. 모델 적재시간은 배속에서 제외됐고, CER은 의미 이해율이나 임상 안전성 수치가 아닙니다. `patient`/`staff`는 입력 파일명상의 그룹으로, 실제 환자·의료진의 신원이나 임상적 대표성을 검증했다는 뜻이 아닙니다. 예비 표본 36쌍과 계획된 신규 40상담 파일럿은 별개입니다.

**재현성 범위:** 원본 음성·전체 정답/전사·모델 가중치·원격 환경 잠금파일은 배포하지 않습니다. [비교 코드](docs/benchmark-method.md)는 과거 방법을 복원한 구현이며 2026-11-16 실제 GPU 추론을 완료했습니다. 새 실행의 입력 지문·코드/가중치 해시·버전·시각을 보존했습니다. 과거 입력의 파일별 해시가 없어 과거 표본과의 바이트 단위 동일성은 증명하지 못하며, 전체 문장별 전사 일치나 긴 임상 상담의 안전성을 검증한 것은 아닙니다.

## GPT-Transcribe 추가 비교

[2026-11-17 동일 36문장 정확도·속도 결과](results/2026-11-17-gpt-transcribe/README.md): `gpt-transcribe`와 Qwen 1.7B 모두 **CER 1.19%(6/504자)**였고, 지정 의료 용어 오류는 **GPT 2/37·Qwen 0/37**이었습니다. 요청 중앙값은 **GPT API 1.07초·상주 Qwen 3.00초**였습니다. Qwen 워밍업은 분리했고, 호출 위치·네트워크가 달라 순수 모델 연산 비교로 해석하지 않습니다. 이번 두 모델은 같은 입력·주석으로 새로 실행했습니다.

## Whisper API와 Qwen 공용 서비스 정확도 재비교

[2026-11-17 동일 원음 36쌍 결과](results/2026-11-17-api-comparison/README.md): Qwen3-ASR 1.7B는 **CER 1.19%(6/504자), 지정 의료 용어 표기 오류 0/37**, OpenAI `whisper-1` API는 **CER 3.17%(16/504자), 용어 오류 5/37**이었습니다. API 값은 자체 호스팅 Whisper turbo 결과와 구분합니다. 원음의 외부 API 이용 허용을 확인한 뒤 실행했습니다. 용어 점수는 이번 출력 전에 고정한 25개 유형의 문자 보존 평가이며 임상 의미 오류 전체나 안전성을 입증하지 않습니다.

## 비교 코드

[확대 비교 실행 방법](docs/expanded-benchmark-method.md): 표본 선택 → 동일 선택의 음성 바이트 검증 → 항목별 재개 가능한 직렬 실행 → 대응 집계. 확대 표본의 실제 모델 추론은 아직 시작하지 않았습니다.

[사용법과 방법 차이](docs/benchmark-method.md)를 먼저 읽으세요. 기존의 별도 모델별 환경과 로컬 가중치를 사용하며 자동 설치·모델 다운로드를 하지 않습니다. 기존 오프라인 비교는 API를 호출하지 않으며, 새 `scripts/compare_api.py`의 OpenAI 실행(`gpt-transcribe` 또는 `whisper-1`)은 외부 음성 이용 승인 플래그와 승인된 프로세스 키가 명시된 경우에만 유료 API를 호출합니다. 허용된 자체 자료에 대해서만 실행합니다. 단일 조건은 `scripts/benchmark.py`, 기존 GPU 잠금을 사용하는 순차 실행은 `scripts/run_suite.py`를 사용합니다. 새 실행 결과는 `private-runs/`에 두고 공개할 집계는 별도로 검토합니다.

```sh
python3 -B -m unittest discover -s tests -v
python3 -B scripts/sample_size_plan.py
python3 -B scripts/benchmark.py --help
```

GPU 추론에 필요한 패키지를 테스트를 위해 설치할 필요는 없습니다. 이 저장소에는 배포 API 서버·자동 실행 서비스·앱 활성화 코드가 포함되어 있지 않습니다.

## 공개 범위

포함: 계획 초안, 공개 문헌 링크, 빈 서식, 집계 수치, 측정 방법과 코드, 합성 테스트.

제외: 원본 음성·영상, 원문 전사, 개별 상담별 결과, 서명 동의서, 환자/치료사 식별자, 비공개 Drive·운영 URL, 자격증명과 내부 접속 정보, 모델 가중치. 합성 fixture는 테스트 중 임시 생성하며 실제 사람의 녹음이 아닙니다.

`.gitignore`와 `scripts/check_publication.py`는 일부 유형·패턴을 점검할 뿐 개인정보 부재를 보장하지 않습니다. 공개할 파일을 명시적으로 선택하고 내용을 검토해야 합니다. 원본 데이터의 이용 조건이 확인되지 않아 데이터를 공개하거나 재배포하지 않습니다.

## 권리·인용

공개 접근과 재사용 허가는 서로 다릅니다. 현재 별도의 재사용 라이선스는 지정하지 않았습니다. 모델·패키지·문헌·데이터의 권리는 각 원저작자와 이용 조건을 따릅니다. 이 저장소는 IRB 승인서나 데이터 이용 허가를 대신하지 않습니다. [인용 정보](CITATION.cff)는 논문 게재를 의미하지 않습니다.
