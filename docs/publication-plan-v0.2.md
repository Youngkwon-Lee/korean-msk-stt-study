# 논문 규모 확장 계획 v0.2

작성일: 2026-11-18. 기존 임상 연구계획 KINELO-MSK-STT-2026-01의 추가 계획이다. 등록된 프로토콜·IRB 승인·완료된 연구를 의미하지 않는다.

## 1. 현재 결정

현재 협력기관, 참여 치료사, 연구 이용 동의가 확인된 실제 상담 녹음은 확보되지 않았다. **공개 의료 음성의 재현 가능한 기술 평가를 먼저 수행하고, 실제 한국어 근골격계 상담의 임상 의미 오류·수정 부담 평가는 후속 연구로 진행한다.** 공개 코퍼스의 문장 수를 늘렸다는 이유로 실제 상담의 유효성이나 안전성을 주장하지 않는다.

기존 36문장은 모델·설정 선정과 도구 개발에 사용한 개발자료로 고정한다. 새 평가의 효과 추정, 독립 검증 또는 임상 표본 수 산출에 재사용하지 않는다. 기존 40상담 파일럿 설명문·동의서·평가표는 계속 미승인 초안이다.

## 3. 공개 코퍼스: 실제 점검 및 표본 고정

출처는 [AI Hub 데이터셋 208: 비대면 진료를 위한 의료진 및 환자 음성](https://www.aihub.or.kr/aihubdata/data/view.do?aihubDataSe=data&currMenu=115&dataSetSn=208&topMenu=100)의 기존 보유 샘플이다. 공식 페이지도 샘플은 이해를 위해 별도 가공되었으며 원본과 다를 수 있다고 명시한다. 전체 데이터셋 1,300시간을 확보하거나 분석한 것이 아니다.

2026-11-18 한국시간에 파일 메타데이터 3,735쌍과 정답 텍스트 3,735개를 확인했다. 텍스트는 연결된 원본 파일 ID로 읽고 로컬 원본 파일 목록과 대조했다. 원본 음성의 바이트 해시·길이·샘플레이트 검증은 아직 수행하지 않았다.

| 항목 | 실제 확인 값 |
|---|---:|
| WAV–TXT 쌍 | 3,735 |
| 짝이 없는 파일 / 정규화 후 빈 정답 | 0 / 0 |

**6개는 원본 폴더/파일명의 코드이며 사람 수가 아니다.** 같은 코드 안에 성별·연령 표기가 다른 파일이 있다. 실제 화자 ID 대응과 녹음 세션의 독립성은 확인되지 않았다. ‘6명’ 또는 ‘화자 독립 검증’이라고 표현하지 않는다. `staff`/`patient`도 원본의 역할 라벨이며 실제 참여자 신원을 검증한 결과가 아니다.

코드별 정렬은 `SHA256(seed:sample_id)`로 고정한다. seed는 20261117이다. 기존 개발 정답과 같은 정규화 문구는 다른 코드에 있어도 제외하고, 같은 코드에서는 동일 정답을 한 번만 선택한다. 서로 다른 코드에 반복되는 문구는 보존하되 같은 `text_group`으로 표시한다. 선택 결과를 보고 좋은 오류율이 나오는 문장만 고르지 않는다.

현재 비공개 선택 manifest의 SHA-256:

`dcfdcac189d11835d0ed28efbf6be3edaeb755a8d321d7b84712ef6b2758b624`

이는 **표본 선택 고정의 지문**이다. 음성 바이트 검증이나 추론 완료를 증명하지 않는다. 파일 경로·ID·정답·개별 선택 목록은 공개하지 않는다. [집계와 방법](../results/2026-11-18-preparation/README.md)을 함께 보존한다.

## 4. 실행 전 자료·권리·정답 검토

기존 36문장의 외부 API 이용 허용은 확인되었지만, 그 확인 기록을 확대 표본 전체의 권리 증빙으로 확대 해석하지 않는다. 확대 범위의 원본 이용 조건, 외부 처리·보존·국외 처리 조건, 논문 집계 공개 범위를 자료 관리자가 확인·기록한다. 공개 접근을 원음 재배포 허가로 취급하지 않는다. 실제 환자 자료의 동의나 윤리심의 면제를 이 공개 코퍼스 평가에서 추정하지 않는다.

미리 선택한 300문장을 2인이 모델 출력을 보지 않고 원음–정답 일치, 알아들을 수 없는 구간, 중복·손상, 녹음 특성을 확인한다. 불일치는 합의하고, 정답 문제의 유형·비율을 집계한다. 문제가 체계적이면 전수 정답 검토가 필요한지 결정한 후 실행한다. 기준 정답 변경 시 선택 목록을 유지한 새 manifest와 변경 사유를 보존한다. 이미 고정한 지문을 조용히 덮어쓰지 않는다.

확인된 화자 메타데이터를 확보하면 분할·불확실성 계획을 **모델 출력 확인 전에** 수정한다. 확보하지 못하면 표본 수·화자 수·독립성의 한계를 그대로 논문에 보고한다.

## 5. 모델과 실행 조건

주 비교 후보는 Qwen3-ASR 1.7B와 GPT-Transcribe다. 기존 36문장의 결과를 본 뒤 정한 후속 비교라는 점을 명시한다. Whisper API `whisper-1`은 보조 비교로 두고, 자체 호스팅 Whisper large-v3-turbo와 동일한 모델로 부르지 않는다. 추가 모델 또는 VAD 조건을 주 비교에 넣을 경우 확대 평가 출력 확인 전에 고정한다.

한국어 지정, 원음, 분할 규칙을 공통 적용하고 정답·환자별 단어 목록을 프롬프트로 주지 않는다. 사전 교정·LLM 교정·요약을 주 비교에 섞지 않는다. Qwen은 기존 모델 환경을 사용하며 revision/가중치 해시·정밀도·디코딩·패키지·GPU/드라이버를 기록한다. API는 요청 시각·요청 모델·반환 모델 라벨·언어 옵션을 기록하며 버전 별칭의 변경 가능성을 명시한다.

일차 정확도 실행은 문장별 직렬 호출로 통일한다. 실패와 시간 제한을 누락 없이 보존한다. 완료된 성공 항목은 재호출하지 않고, 응답 수신 여부가 불명확한 중단 건은 자동 재실행하지 않는다. 명시적 실패의 재시도는 근거 확인 후 한 번까지이며 원래 실패도 보존한다. GPU는 기존 잠금을 사용하고 다른 작업을 중지하거나 잠금을 강제 해제하지 않는다.

실행 전 원음을 해시로 검증하여 run-ready manifest를 **새 경로에** 저장한다. 현재 선택 지문과 실행 지문의 연결 기록, 동일한 선택 ID 집합·정답 지문을 보존한다. 준비 단계의 `run_ready_audio_hashes=false` manifest로는 실행기가 API를 호출할 수 없다.

속도는 첫 요청·모델 적재·워밍업 여부를 따로 기록한다. 사전 선정한 120개는 따뜻한 모델의 직렬 HTTP 지연과 음성 길이 대비 처리시간을 보고하는 별도 분석 집합이다. 현재 실행기는 첫 요청을 조용히 버리지 않으며, 차가운 시작을 구분하려면 기존 개발 음성으로 워밍업을 완료하고 시각을 기록한다. API와 로컬 서버의 네트워크 경로 차이를 순수 모델 연산 성능으로 해석하지 않는다. 동시 호출 처리량 측정은 직렬 지연 측정과 분리한다.

## 6. 공개 코퍼스 평가와 분석

주 기술 지표는 같은 원음의 문자 오류 수/정답 문자 수(CER)이며 기존 정규화 규칙을 잠근다. 기술 실패율은 전체 1,800개를 분모로 별도 보고한다. 모델 둘 다 정상 출력한 공통 집합의 대응 CER 차이를 제시하고, 실패 항목을 정답 전체 삭제로 가정한 민감도 수치를 함께 제시한다. 이 가정은 관찰된 전사 CER 또는 임상 오류 판정과 구분한다. 빈 텍스트를 정상 응답한 경우는 실제 전체 누락으로 채점한다.

1,800문장이나 문자를 독립 환자로 취급하지 않는다. 동일 정답 문구를 묶은 대응 재표집 2,000회·seed 20261117·95% percentile 구간은 **관찰 코퍼스에 조건부인 기술적 민감도 구간**으로만 표시한다. 모르는 화자 의존성을 보정하지 못하므로 모집단 신뢰구간이나 임상적 우월성 검정으로 보고하지 않는다. 화자 대응을 확보하면 화자/세션 수준 분석을 출력 확인 전에 별도 고정한다. 현재 도구는 모집단 p값을 생성하지 않는다.

기존 25개 용어 사전은 개발 표본에 맞춘 탐색적 문자 보존 도구다. 0건 오류를 의미 보존·안전성의 증거로 해석하지 않는다. 확대 표본의 용어 평가에는 정답만을 보고 범위·용어/표현·문맥을 고정하고 포함 항목의 분모를 공개한다. 중첩·다의어·동의 표현을 사전 처리하고, 두 모델 출력에 같은 주석을 적용한다. 해당 주석이 없으면 오류를 0으로 쓰지 않고 미평가로 표시한다.

중요 정보 오류 평가는 별도 확보한 물리치료사 2인이 모델명에 눈가림하여 수행한다. 먼저 정답에서 신체 부위/측·수치/단위·부정·증상 경과·조치 정보 단위를 확정하고, 모델의 누락/대체/추가를 판정한다. 합의 전 평가, 단순 일치율, kappa와 그 한계, 중재 결과를 남긴다. 공개 샘플에서 이런 항목의 실제 포함 빈도를 보고하고 부족한 근골격계 항목을 인위적으로 채워 넣지 않는다. 현재 임상 의미·용어 오류 값은 새 확대 표본에서 미평가다.

## 7. 후속 실제 상담 연구와 표본 수

권고는 [기존 임상 계획](protocol.md)의 **서로 다른 환자 40상담 외부 파일럿**을 유지하는 것이다. 2기관 이상·8치료사 이상을 모집 목표로 하되 확보한 것처럼 적지 않는다. 실제 녹음 전 기관 책임자, IRB 심의/면제 판단, 설명·동의, 처리 장소와 외부 API 범위를 확정한다. 원본 음성·건강정보를 공개 Git 또는 일반 공유 폴더에 올리지 않는다.

임상 주 결과는 상담당 중요 임상 의미 오류 또는 전사 실패가 하나 이상인 비율이며 구성요소를 따로 보고한다. 파일럿은 효과를 입증하는 검정이 아니라 중요 오류 빈도, 대응 불일치쌍, 치료사별 이질성, 평가 일치도, 수정시간·탈락률의 추정에 사용한다. 파일럿 자료는 개발·주석 교육에 썼다면 독립 본연구에 합산하지 않는다.

본연구 N은 임상적으로 의미 있는 최소 차이를 먼저 정하고, 파일럿의 `p10`(A만 오류), `p01`(B만 오류), 치료사별 상관, 기관/치료사 수, 상담 수 불균형과 탈락을 반영한 **대응·군집 모의실험**으로 확정한다. 파일럿 상관 하나를 확정값으로 믿지 않고 보수적 범위를 함께 평가한다. 실제 상담의 위험차를 목표로 분석 모형과 검정력 모의실험의 분석법을 일치시킨다. 80%와 90% 검정력을 비교하고 효과·군집 수·결측 가정별 민감도를 보고한다.

기존 근사 예시에서 15%p 차이(p10=.20, p01=.05)는 독립 상담 약 85건, 10%p 차이(.20/.10)는 234건이다. 치료사당 5상담·차이의 군집상관 .05·15% 비평가를 **가정하면** 약 120건·331건으로 증가한다. 이는 관찰된 효과나 확정 모집 수가 아니다. 고정된 8치료사에게 상담만 계속 늘리면서 동일 설계효과를 적용하지 않는다. [계산 가정과 18개 예시](../results/sample_size_scenarios.csv)를 보존하며, 36문장의 6/504자 오류로 임상 N을 산출하지 않는다. 대응 이분형 검정의 제한은 [Fagerland 등](https://doi.org/10.1186/1471-2288-13-91)을 참고하되 일반 McNemar가 치료사 군집성을 해결한다고 가정하지 않는다.

## 8. 제출 전 완료 조건과 현재 상태

현재 완료: 원본 쌍·정답 전체 점검, 개발 문구 제외, 1,800개 선택 고정, 300개 정답 검토/120개 속도 하위표본 선정, 재개 가능한 실행기와 대응 집계 도구, 합성 경계 테스트, 공개 집계 준비.

아직 미완료: 확대 표본의 이용 범위 기록, 화자/세션 메타데이터 확인, 원음 해시·길이 점검, 모델 출력과 독립된 정답 검토, 실제 확대 모델 실행, 용어/중요 정보 이중 주석, 분석과 불확실성 점검, 원고 작성·투고. 임상 후속 연구는 기관·심의·모집부터 별도 진행해야 한다.

제출 시 데이터 출처·접근 조건, 개발/평가 분리, 선택 흐름도, 실제 화자 수의 확인 수준, 누락/실패, 환경·모델 버전, 정답 검토와 눈가림, 정규화·주석 정의, 편향·일반화 한계를 보고한다. 진단 정확도 연구가 아닌 원시 ASR 평가에 [STARD-AI](https://www.nature.com/articles/s41591-025-03953-8)를 그대로 적용하거나 준수 인증을 주장하지 않는다.

**이번 결과는 논문을 위한 확대 실험의 준비 완료이며, 확대 실험 완료나 논문 게재 수준의 증거 확보를 의미하지 않는다.** 원본·정답·개별 결과는 비공개로, 공개 저장소에는 방법·코드·빈 양식·검토한 집계만 둔다.
