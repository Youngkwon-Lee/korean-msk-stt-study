# 300건 원음 기반 정답 검토 도구

고정된 `reference_review_substudy` 300개만 로컬에서 검토한다. 원음·제공 정답·현재 검토자의 수정 내용만 화면과 API에 전달한다. 모델 결과 디렉터리나 비교 결과 파일을 읽지 않는다. 원래 manifest와 정답은 변경하지 않는다.

## 실행

Python 표준 라이브러리만 사용하며 설치·GPU·외부 API가 필요하지 않다. 원음과 명세는 비공개 작업 공간에 두고 기존 manifest SHA-256으로 고정한다.

```sh
python3 -B scripts/review_app.py \
  --manifest /path/to/private/run-ready-manifest.json \
  --expected-manifest-sha256 EXPECTED_SHA256 \
  --audio-root /path/to/private/selected-audio \
  --db private-runs/reference-review-300/reviews.sqlite3 \
  --reviewer reviewer-1 --port 8767 --allowed-host stt-review.localhost
```

`aside-local stt-review 8767 --url-only`로 분리된 로컬 주소를 확인한 뒤 Aside에서 연다. 서버는 `127.0.0.1`에만 바인딩하며 다른 앱의 포트가 사용 중이면 시작하지 않는다. 종료는 실행 터미널에서 Ctrl+C다. 같은 명세·DB·검토자 ID로 다시 시작하면 저장 내역이 복원된다. 기존 8766 포트는 다른 로컬 서비스나 SSH 터널이 점유할 수 있으므로 해당 프로세스를 종료하지 않고 별도 포트(기본값 8767)를 사용한다. 재시작 시 브라우저 주소와 `--port`를 일치시키고, `/api/session`이 이 검토 도구의 응답인지 확인한 뒤 원음 재생을 검증한다.

## 검토 흐름

1. 원음을 재생한다. 재생 속도를 바꾸거나 처음부터 다시 들을 수 있다.
2. 제공 정답을 확인하고 검토 정답을 수정한다. 잠시 입력을 멈추면 초안을 저장한다.
3. `음성을 듣고 정답을 확인했습니다`를 선택하고 `저장하고 다음` 또는 ⌘/Ctrl+Enter로 완료한다. 한국어 조합 중에는 완료 단축키와 자동 저장을 실행하지 않는다.
4. 불명확한 항목은 메모를 쓰고 보류로 저장한다. 초안과 보류는 완료 수에 포함하지 않는다.
5. 기록 내보내기로 현재 검토자의 정답·수정 내역·이력을 JSON 파일로 받는다. 이 파일에도 원문과 개별 결과가 들어 있으므로 비공개로 취급한다.
6. 300건을 모두 완료한 뒤 별도 `rescore-reference-review.command`를 실행하면 고정된 두 모델 출력으로 CER·지정 의료 용어 문자열 오류를 재계산하고 논문용 표를 만든다. [재평가 방법과 출력 범위](reference-rescoring.md)를 따른다. 미완료 상태에서는 결과표를 만들지 않는다.

청취 확인은 검토자의 명시적 확인과 브라우저 재생 구간 기록이며 실제 청력을 검증하는 장치가 아니다. 자동화 검증은 합성 자료만 사용하고 실제 300개 항목의 임상 판정은 채우지 않는다.

## 독립 QA와 데이터 이용권

외부 검수·모델 재학습·승인된 평가용 참조 텍스트 반출은 이 화면의 단일 검수 완료와 별개입니다. 현재 로컬 검수자 ID는 인증 계정이 아닙니다. [검수 품질·이용권·별도 승인 게이트](review-release-governance.md)를 확인하고, 실제 승인 전에는 외주 접속이나 학습용 데이터 제공을 시작하지 않습니다.

## 저장과 독립성

SQLite에 현재 검토 상태와 모든 저장 버전·시각을 트랜잭션으로 남긴다. 빈 초안도 보존하며 원래 제공 정답으로 조용히 되돌리지 않는다. 오래된 버전의 저장 요청은 409로 거절해 다른 창의 수정을 덮어쓰지 않는다. 충돌 시 현재 입력을 보존한 뒤 저장된 내용을 다시 불러와 조정한다.

두 번째 검토자는 **다른 검토자 ID**(`reviewer-2`)로 실행한다. 같은 DB를 사용할 수 있지만 API와 내보내기는 실행 중인 검토자의 기록만 반환한다. 화면에는 검토자 전환 기능이나 다른 검토자의 수정 결과가 없다. 검토자 ID는 작업 분리를 위한 식별자이며 사용자 인증 계정은 아니다. 다른 사람에게 네트워크로 공개하는 서비스로 사용하지 않는다.

실행 예시는 두 번째 서버에 `--reviewer reviewer-2 --port 8768 --allowed-host stt-review-second.localhost`를 사용한다. 서로의 검토 결과를 보지 않고 검토한 뒤 별도의 중재 단계에서 조정한다. 원음·정답이 바뀌면 기존 DB를 재사용하지 않고 새 명세/DB를 만든다.

HTTP는 정확히 선택한 항목만 제공하며 경로 입력이나 디렉터리 열람을 허용하지 않는다. 음성 탐색은 단일 byte range를 지원한다. 저장에는 세션 토큰·동일 출처 검사를 사용하고 응답은 캐시하지 않는다. 새 브라우저 탭에서 같은 검토자·항목을 동시에 편집할 때 충돌 방지가 적용된다.

## 공개 범위와 검증

공개 대상은 도구 코드·설명·합성 테스트다. SQLite, 원음, 제공 정답, 검토 내보내기와 화면 증거는 비공개로 보존한다. 다른 파일을 자동으로 탐색하거나 모델 출력을 숨긴 채 사전 입력하지 않는다. 검토 정답의 초기값은 제공 정답이다.

서버 테스트는 선택 집합/해시, 저장 후 재시작, 이력, 빈 초안, 검토자 분리, 버전 충돌, 청취 확인, 다른 DB 보존, 모델 결과 비노출, 음성 범위·미선택 파일 차단, 출처·토큰 검사를 확인한다. 실제 검토 도구 동작과 임상 정답의 타당성은 별도다.

2026-11-18 확인: 관련 테스트 8개 통과. Aside의 별도 합성 표본에서 한국어 문자 수정, 초안 자동 저장·새로고침 복원, 음성 재생, 청취 확인 후 완료·다음/이전 이동, 내보내기 응답을 확인했다. 1280px 화면과 390px 화면을 점검했고 좁은 화면의 가로 넘침은 없었다. 실제 300건 화면은 원음 준비 상태와 제공 정답 초기값, **0/300 완료·검토 기록 0건**을 읽기 전용으로 확인했다. 물리 키보드의 실제 IME 조합, 다른 기기 접속, 다중 사용자 인증, 임상 판정은 검증 범위에 포함하지 않는다.
