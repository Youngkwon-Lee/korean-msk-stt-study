# 확대 코퍼스 실행 변경 기록 v0.2a

2026-11-18. 확대 표본의 모델 출력을 확인하기 전에 고정한 실행 변경이다. 선택 1,800개·기존 개발 문구 제외·정답 문구 그룹·평가/속도 하위표본·정규화 규칙은 변경하지 않는다.

- 확대 1,800문장의 외부 API 이용 허용을 사용자가 명시적으로 확인했다. 기존 키 재사용 승인을 유지한다.
- 정확도 단계는 GPT-Transcribe 동시 요청 최대 4개, Qwen3-ASR 1.7B 오프라인 배치 최대 4개로 실행한다. 초기 계획의 전 항목 직렬 실행을 계산 자원과 실행시간을 고려해 변경한다. 배치 크기·동시 요청 수가 다름을 보고하며 그 단계의 요청 시간을 직렬 지연으로 사용하지 않는다. 배치 크기를 정확도 결과가 좋은 쪽으로 사후 선택하지 않는다.
- 정확도 실행 이후 기존에 선정한 120개를 별도 직렬 단계로 다시 실행한다. GPT는 동시 요청 1개, Qwen은 유효 배치 1개다. 이 출력으로 전체 정확도 결과를 대체하지 않으며 두 단계 사이 출력 변화도 별도로 보고한다.
- Qwen은 기존 PyAV mono 16 kHz 디코더, float16, eager attention, Korean, max_new_tokens=1024를 유지한다. Qwen은 로컬 디코드+추론 시간, GPT는 HTTP 왕복 지연으로 측정하므로 순수 모델 연산 성능의 직접 비교로 해석하지 않는다. 모델 적재 및 합성 무음 워밍업은 별도다. 원음 검증에서 최장 31.5초가 확인되어 최초 실행 전 길이 점검이 중단되었으며 이때 API 호출은 없었다. 30초 초과 파일도 제외하지 않고 기존 Qwen 서비스와 동일하게 30초씩 분할한 뒤 비어 있지 않은 결과를 한 칸 띄어 이어 붙인다. GPT는 동일한 원음 전체를 입력한다.
- 독립 전문가의 원음–정답 검토 전에 원래 제공 정답 기준의 **탐색적 기술 실행**을 먼저 한다. 기준 정답은 고정하며, 향후 검토자는 모델 출력을 보지 않아야 한다. 정답 수정이 필요하면 기존 결과를 덮어쓰지 않고 버전·수정 사유와 민감도 결과를 남긴다. 이번 실행은 임상 주분석이나 독립 검토 완료를 의미하지 않는다.
- 기존 25개 개발 사전으로 정답에서만 자동 생성한 탐색적 문자열 주석은 699회/624문장이다. 주석 SHA-256은 `9aca48fd818ff36cdf859ffe331a31c111d109c2919c00c57ba4a53280cc06b1`이다. 다의어·문맥·임상적 심각도는 검토하지 않았으므로 이를 검증된 의료 의미 오류 척도로 부르지 않는다.

원음은 암호화 전송 후 양쪽 SHA-256을 대조한다. 개별 정답·전사·전송 URL·복호화 자료는 공개하지 않는다. 실패·모호한 중단 건은 자동 재시도하지 않는다. 전송용 암호화 사본은 검증 후 정리하고 원본 Drive 자료는 보존한다. 실제 모델 결과는 별도 날짜의 집계와 실행 증거로 기록한다.
